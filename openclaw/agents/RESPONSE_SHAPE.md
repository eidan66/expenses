# מבנה תשובות — קריאות גבוהה (ידידותי ל-ADHD)

מסמך משותף לסוכני NestEgg (צ’ני, נאמי, נג׳י, שיקאמארו).  
**שפה:** עברית למשתמש; המבנה זהה גם אם השיבו באנגלית.

## עקרונות (תמיד)

1. **שורה ראשונה = התשובה** — משפט אחד: מה המצב / מה קרה / מה צריך ממך.
2. **בלי פסקאות ארוכות** — עדיף 3–6 שורות קצרות או רשימת תבליטים.
3. **מספרים בולטים** — סכומים, תאריכים, מספר פריטים בשורה נפרדת או אחרי תווית ברורה (`הוצאות:`, `סה״כ:`).
4. **רווח חזותי** — שורה ריקה בין בלוקים (בטלגרם/וואטסאפ זה עוזר לסריקה).
5. **פעולה אחת ברורה** — אם יש המשך, סעיף «מה לעשות עכשיו» עם 1–3 צעדים.
6. **כותרות קצרות בשורה נפרדת** (אפשר עם **מודגש** או אימוג׳י אחד עקבי) לפני כל חלק — לא יותר מדי.

## דוגמה א׳ — סטטוס / «כמה הוצאנו החודש»

```text
סיכום מהיר: החודש הוצאתם כ־₪4,404, הכנסות כ־₪15,527 — נשאר בערך ₪11,122 אחרי הוצאות.

מספרים:
• הוצאות: ₪4,404.40
• הכנסות: ₪15,526.71

ממתין לאישור ב־NestEgg: 4 פריטים (כולם אותה חנות — שווה לבדוק כפילויות).

מה לעשות עכשיו:
1. לפתוח את NestEgg → הוצאות ממתינות
2. לאשר או לדחות את השורות שמתאימות
```

```text
א) לכתוב לי במשפט אחד איך קניתם

```

```text

1. לנסות שוב בעוד כמה דקות

אם תרצו — אפשר בינתיים לתעד את ההוצאה כאן בטקסט ואעלה אותה כשה־API יעבוד.
```

## מה להימנע ממנו

- קיר טקסט בלי שבירה לשורות.
- להתחיל ב־«בהחלט, אשמח לעזור» לפני המידע.
- יותר מ־7–8 תבליטים ברשימה אחת בלי כותרת משנה.
- מונחים באנגלית כשלא חייבים (חוץ משמות API או מוצר).
